Juan Alejandro Carrillo Jaimes · Est. Maestría Ciencia de Datos
Basado en el análisis de la tesis "Modelo predictivo para la detección temprana del riesgo de deserción estudiantil en la Pontificia Universidad Javeriana Cali — SAT", se identificaron cuatro modelos de clasificación y sus respectivas métricas de validación. El proyecto utilizó un conjunto de 1.957 registros con 97 variables sociodemográficas y académicas para predecir deserción universitaria con Machine Learning.

🔁Técnicas de Validación Cruzada
✂️
K-Fold CV
Divide el conjunto en K particiones. El modelo se entrena K veces usando K-1 folds. Se usaron 10 particiones para mayor robustez. Aplicado en SVM, RF y NNET.
🔄
Repeated CV
El proceso K-Fold se repite 5 veces con particiones aleatorias diferentes. Reduce la varianza de las estimaciones. Estrategia ideal para datasets pequeños (n<2000).
🎯
Resampling & Tuning
Búsqueda de hiperparámetros óptimos mediante grilla (Grid Search) evaluada en cada fold. Garantiza que los parámetros no generen sobreajuste al conjunto de entrenamiento.
📊Métricas de Evaluación
TP+TN / Total
Accuracy
Proporción de predicciones correctas sobre el total. Principal métrica del estudio. Línea base: 62%.
(Po - Pe) / (1 - Pe)
Kappa
Mide acuerdo entre predicciones y realidad, ajustando por coincidencia aleatoria. Valores >0.7 indican acuerdo sustancial.
TP / (TP + FP)
Precisión
De todas las predicciones de deserción, ¿cuántas fueron realmente desertores? Reduce falsos positivos.
TP / (TP + FN)
Recall / Sensib.
De todos los desertores reales, ¿cuántos detectó el modelo? Crítico para no perder casos de riesgo.
Matriz de Confusión
Pred: No deserta Pred: Deserta
Real: No deserta TN ✓ FP ✗
Real: Deserta FN ✗ TP ✓
TP Verdadero Positivo · TN Verdadero Negativo
FP Falso Positivo · FN Falso Negativo
Pruebas Estadísticas de Comparación
Friedman
Prueba no paramétrica para comparar múltiples modelos. Con α=0.05 no se encontraron diferencias significativas entre los cuatro modelos.
Wilcoxon
Test post-hoc por pares. Confirmó que ningún modelo supera estadísticamente a los demás en capacidad predictiva.
Error Test
Validación final con datos de prueba: todos los modelos mantienen exactitud sobresaliente, confirmando ausencia de sobreajuste.
